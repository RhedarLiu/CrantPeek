快捷查询，即用即走。

提供 macOS Apple Silicon、Windows x64 便携版与安装包。ZIP 包内包含完整离线词典及许可证；Windows 便携版请解压后运行 `CrantPeek.exe`，保留同目录资源文件。`SHA256SUMS.txt` 用于验证三个包的完整性。

本版包含更可靠的 macOS 跨应用取词、“关于”设置页，以及 正式版更新检查；官网下载按钮自动获取最新版。

macOS 未经过发行公证，CI 打包未配置发行签名；Windows 未配置发行代码签名，安装包实机验收尚未完成。系统可能提示首次打开限制，请确认下载来源后按系统提示操作。Windows OCR 需要对应语言包。

离线词典与系统 OCR 在本机运行。在线翻译与 AI 服务需要用户自行配置，查询文字会发送至选定的服务；图片理解当前仍处于规划阶段。
