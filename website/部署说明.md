# Crant Peek 官网

部署域名：**https://crantpeek.eno.ink**。网站是纯静态 HTML、CSS、JavaScript，无需 Node.js、数据库或构建工具。视觉采用与应用一致的 Noto Serif、黑白配色与圆角组件；没有外部 CDN 依赖。

## 文件

- `public/`：上传到服务器的完整网站，包含演示视频、字体和本地准备的下载文件。
- `nginx.conf`：HTTP 站点配置；HTTPS 可交给已有反向代理，或由 Certbot 配置。
- `public/index.html`：页面文案与三个站内下载地址，当前程序对应 `b6ca7f1` 测试构建。
- `public/downloads/`：macOS ZIP、Windows 便携 ZIP、Windows 安装 EXE，由 nginx 直接提供下载。此目录不提交到 Git，当前本地副本已经准备好。
- `prepare-downloads.py`：从已有构建产物准备下载文件并生成 SHA256 校验值，不会在访客下载时调用 GitHub。

## 准备下载文件

当前本机的 `public/downloads/` 已放好三个包，上传完整 `public/` 即可。如果从 Git 仓库重新克隆官网源码，先把已有的三个构建产物放进下载目录：

```sh
python3 website/prepare-downloads.py \
  --macos /path/to/Crant-Peek-macOS.zip \
  --windows-portable /path/to/Crant-Peek-Windows.zip \
  --windows-installer /path/to/Crant-Peek-Windows-Setup.exe
```

脚本会检查 ZIP 完整性和应用入口、检查 EXE 文件头，再复制为固定文件名。上线前确认以下文件都已上传；缺少文件时 nginx 会返回 404，不会自动跳转到 GitHub：

```text
public/downloads/Crant-Peek-macOS.zip
public/downloads/Crant-Peek-Windows.zip
public/downloads/Crant-Peek-Windows-Setup.exe
public/downloads/SHA256SUMS.txt
```

## 部署

先将域名 DNS 指向你的服务器，确认服务器已有 nginx，且没有另一个配置占用相同域名。将本目录复制到服务器，例如 `/tmp/crantpeek-website`，然后执行：

```sh
sudo mkdir -p /var/www/crantpeek/public
sudo cp -R /tmp/crantpeek-website/public/. /var/www/crantpeek/public/
sudo find /var/www/crantpeek/public -type d -exec chmod 755 {} \;
sudo find /var/www/crantpeek/public -type f -exec chmod 644 {} \;
sudo cp /tmp/crantpeek-website/nginx.conf /etc/nginx/conf.d/crantpeek.conf
sudo nginx -t
sudo systemctl reload nginx
```

配置依赖 nginx 的全局 `http` 块已加载系统 `mime.types`，常见默认安装已包含。自定义 nginx 配置时请确保 `video/mp4`、字体及 JavaScript 类型正确，避免视频与脚本无法加载。

上述配置先提供 HTTP。如果服务器前面已有 HTTPS 反向代理，将其上游指向此站点即可。如果由这台 nginx 直接提供 HTTPS，安装适合服务器系统的 Certbot 与 nginx 插件后执行：

```sh
sudo certbot --nginx -d crantpeek.eno.ink
sudo certbot renew --dry-run
```

Certbot 会申请证书并配置 HTTPS / HTTP 跳转。直接申请时需让域名解析生效、80 和 443 端口可访问。不能只上传文件就自动获得 HTTPS。

## 检查

打开网站，检查 macOS 下载、Windows 默认便携版、Windows 下拉安装包，以及视频播放和拖动进度。窄屏下也应能完整访问下载菜单。三个包由你的网站服务器直接发送，访客不需要访问 GitHub。nginx 配置包含附件下载响应、范围请求支持和禁用缓存设置。

```sh
curl -I https://crantpeek.eno.ink/
curl -I https://crantpeek.eno.ink/assets/demo.mp4
curl -I -H 'Range: bytes=0-1023' https://crantpeek.eno.ink/assets/demo.mp4
curl -I https://crantpeek.eno.ink/downloads/Crant-Peek-macOS.zip
curl -I https://crantpeek.eno.ink/downloads/Crant-Peek-Windows.zip
curl -I https://crantpeek.eno.ink/downloads/Crant-Peek-Windows-Setup.exe
```

视频范围请求应返回 `206 Partial Content`；三个下载链接应返回 `200` 和 `Content-Disposition: attachment`，不应返回指向 GitHub 的跳转。nginx 默认支持静态文件范围请求，无需额外视频模块。

## 更新下载版本

用新的同版本构建产物重新运行准备脚本，上传三个下载文件与校验值，并同步 `public/index.html`「版本与反馈」中的提交编号。网页下载地址保持不变。正式升级时尽量在维护窗口一并替换三个文件，避免双端文件来自不同版本。

首页已注明 macOS 为 Apple Silicon、Windows 为 x64、安装包未测试，以及实机测试、签名、OCR、图片理解和本地凭据存储限制。正式发行与实机验收完成后，再按实际情况更新这些文案。
