# Crant Peek 官网

部署域名：**https://crantpeek.eno.ink**。网站是纯静态 HTML、CSS、JavaScript，无需 Node.js、数据库或构建工具。视觉采用与应用一致的 Noto Serif、黑白配色与圆角组件；没有外部 CDN 依赖。

## 文件

- `public/`：上传到服务器的完整网站，包含演示视频和字体。
- `nginx.conf`：HTTP 站点配置；HTTPS 可交给已有反向代理，或由 Certbot 配置。
- `public/index.html`：页面文案与三个下载地址，默认使用已存在的 `test-b6ca7f1` 测试构建。应用未更改，因此本次无需重编译程序。

## 部署

先将域名 DNS 指向你的服务器，确认服务器已有 nginx，且没有另一个配置占用相同域名。将本目录复制到服务器，例如 `/tmp/crantpeek-website`，然后执行：

```sh
sudo mkdir -p /var/www/crantpeek/public
sudo cp -R /tmp/crantpeek-website/public/. /var/www/crantpeek/public/
sudo find /var/www/crantpeek/public -type d -exec chmod 755 {} \;
sudo find /var/www/crantpeek/public -type f -exec chmod 644 {} \;
sudo cp /tmp/crantpeek-website/nginx.conf /etc/nginx/conf.d/crantpeek.conf
sudo nginx -t
sudo systemctl reload nginx
```

配置依赖 nginx 的全局 `http` 块已加载系统 `mime.types`，常见默认安装已包含。自定义 nginx 配置时请确保 `video/mp4`、字体及 JavaScript 类型正确，避免视频与脚本无法加载。

上述配置先提供 HTTP。如果服务器前面已有 HTTPS 反向代理，将其上游指向此站点即可。如果由这台 nginx 直接提供 HTTPS，安装适合服务器系统的 Certbot 与 nginx 插件后执行：

```sh
sudo certbot --nginx -d crantpeek.eno.ink
sudo certbot renew --dry-run
```

Certbot 会申请证书并配置 HTTPS / HTTP 跳转。直接申请时需让域名解析生效、80 和 443 端口可访问。不能只上传文件就自动获得 HTTPS。

## 检查

打开网站，检查 macOS 下载、Windows 默认便携版、Windows 下拉安装包，以及视频播放和拖动进度。窄屏下也应能完整访问下载菜单。GitHub 下载跳转由浏览器直接完成，服务器无需代理安装包。

```sh
curl -I https://crantpeek.eno.ink/
curl -I https://crantpeek.eno.ink/assets/demo.mp4
curl -I -H 'Range: bytes=0-1023' https://crantpeek.eno.ink/assets/demo.mp4
```

最后一项应返回 `206 Partial Content`。nginx 默认支持静态文件范围请求，无需额外视频模块。

## 更新下载版本

在 `public/index.html` 中替换所有对应 Release 的三个下载链接，并同步「版本与反馈」中的提交编号。先确认 Release 里已经存在对应资产，再更新网页；当前链接固定到已有测试构建，避免 GitHub `latest` 排除预发布版本造成下载失败。

首页已注明 macOS 为 Apple Silicon、Windows 为 x64、安装包未测试，以及实机测试、签名、OCR、图片理解和本地凭据存储限制。正式发行与实机验收完成后，再按实际情况更新这些文案。

字体为 Noto Serif（SIL Open Font License），许可证随 `public/assets/` 提供。演示素材和项目文案来自本项目；程序源码采用 MIT 许可。
