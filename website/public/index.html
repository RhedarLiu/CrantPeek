开始使用

选中，按一下，答案就在旁边。

  1. 01

    打开应用，完成引导

    macOS 按引导授权辅助功能、输入监控及屏幕录制；Windows 便携版解压后打开 CrantPeek.exe。

  2. 02

    选择你使用的渠道

    添加翻译或 AI 服务，排列「快速翻译」的顺序，为「追问」选择一个 LLM。Google 翻译无需 API key，网络须能连接 Google。

  3. 03

    继续阅读，随时查询

    选中文字后按快捷键。读取不到选区时，也可以直接输入或粘贴。Enter 提交，Shift + Enter 换行。

本地优先

离线词典在本机，在线渠道由你选择。

词典和系统 OCR 在本机运行；使用在线服务时，查询文字会发送到你配置的渠道。API key 保存在本机配置目录的独立凭据文件中，未加密，请妥善保护。支持 Google、DeepLX、OpenAI 兼容协议、Anthropic 和 DeepSeek。

下载之前

下载前，了解这些细节。

正式版本仍在持续完善，请留意平台支持与首次打开方式。

平台与测试情况

macOS 已有较完整的测试。Windows 部分功能仍需实机验证，可能存在缺失或不完善；安装包尚未测试，建议先用便携版。

当前 macOS 包为 Apple Silicon，Windows 包为 x64。未提供原生 Windows ARM64 包，ARM 设备上的兼容性未验证。

签名与首次打开

macOS 使用开发签名，尚未经过发行公证，系统可能阻止首次打开。请核对下载来源，再按系统提示允许打开并授权。

Windows 未配置发行代码签名，可能出现安全提示。请核对下载来源，再按系统提示运行。

文字读取与截图

选区读取受来源应用和系统权限影响。Windows OCR 依赖系统语言包，识别效果可能不佳；读取管理员运行的应用也可能受权限限制。

截图目前仅用于提取文字，规划中的图片理解功能尚未开发。

版本与反馈

下载链接会自动获取最新正式版，无需手动选择版本。在线翻译与 AI 功能需要你自行配置服务和网络。

遇到问题，可以在 GitHub Issues 反馈，并注明系统版本、来源应用和复现步骤。
